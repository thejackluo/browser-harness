Your helper is installed.

Finish these Chrome steps once. No terminal, Git, Node installation, or gateway shortcut is needed.

  1. Open chrome://extensions in Chrome and turn on Developer mode.
  2. Click Load unpacked and select the extension folder opened by the installer. It is inside %LOCALAPPDATA%\Programs\BrowserHarness. If you already have Browser Harness, remove the old entry before loading this copy.
  3. Open ChatGPT, sign in normally and choose your model. Click the Browser Harness extension, then Arm this tab.

Use Configure Hermes or Configure OpenCode in the popup if you have that agent installed. Keep Chrome and the armed tab open while using your agent.

The helper starts automatically and stops when Chrome disconnects. Gemini remains experimental.

For preview updates, run the newer installer, reload the extension, and refresh your chat tabs. Automatic extension updates require a future Chrome Web Store release.
