Get ready once. Then just use the extension.

  1. Run BrowserHarnessSetup.exe from the Windows download. It installs a private background helper for your Windows user; no Node or Git installation is needed.
  2. If you have not loaded the extension yet, follow the installer's guide. Chrome requires Developer mode and Load unpacked until a Web Store version is published.
  3. Open ChatGPT, sign in normally, choose your model, then open this extension and click Check again and Arm this tab.
  4. Use Configure Hermes or Configure OpenCode if you have that agent installed. These buttons update the agent's configuration; they do not install or run it.

Keep Chrome and your armed tab open. You do not need a gateway window or a desktop shortcut.

If upgrading from the terminal version, close its gateway window once before starting the helper. To update a preview install, rerun the newer installer, reload the extension in chrome://extensions, and refresh your chat tabs.

The helper cannot install itself from inside Chrome. If you only received an extension folder, ask its distributor for the matching Windows installer. This project is not yet distributed through the Chrome Web Store.
